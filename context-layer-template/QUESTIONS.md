# Open questions

Agents add a line here when a task needed context no file had. Format: `- [ ] <file it belongs in>: <the question> (<date>, <which task hit it>)`. Answer it in the file it belongs in, with a tag, then delete the line.

The loop's weekly review flags any line older than 14 days.

- [ ] `context/icp.md`: which company sizes, stages and industries are a hard no? (YYYY-MM-DD, bootstrap)
- [ ] `context/personas.md`: who signs, and who only recommends? (YYYY-MM-DD, bootstrap)
- [ ] `context/suppression.md`: where does the current customer list come from, and how often is it refreshed? (YYYY-MM-DD, bootstrap)
